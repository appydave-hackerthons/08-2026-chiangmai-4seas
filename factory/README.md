# Factory — How to Run This Again

The hackathon is one run of a method. This folder holds the method so we can run it again on a different city, different theme, different problem.

## The factory inputs

- **People:** 5 (or more) willing to be interviewed for 5 minutes
- **Theme:** any behavior gap (wellness, connection, learning, climate, career, loneliness)
- **Time:** 1-2 hours of interviews + 30 min synthesis + 30 min ideation + 30 min build + 30 min demo

## The factory process

### Step 1: Interview (5 min each, dynamic)

Lead: Ethan (or anyone with good follow-up discipline)
Tool: prompt bank (`interview-script.md`)
Goal: surface the stuck point, the workaround, the smallest step

### Step 2: Extract (60 sec per interview)

For each interview, write down:
- The stuck point (one sentence)
- The smallest step (verbatim)
- The best quote
- The workaround

Pass to Karlen for story weaving.

### Step 3: Pattern match (15 min)

Karlen reads the extracted stuck points. Identifies:
- The dominant stuck (what 3+ people share)
- The outlier stuck (what 1-2 people have that's unique)
- The workaround pattern (what people are already doing to cope)

### Step 4: Ideate (15 min)

For each distinct stuck point, generate 3-5 micro app ideas. SCAMPER them. Pass through the 12 frames. Pick the strongest.

### Step 5: Decide (5 min)

What do we demo?
- One strong micro app (if ideation lands)
- The nudge web app (if stuck points are generic)
- A framework/protocol (if neither but the method is interesting)
- Whatever else surfaced (let the data drive)

### Step 6: Build (varies)

Dave builds the chosen artifact. Could be:
- Working code (Telegram bot, web app)
- Paper prototype
- Sketch + mockup
- Framework diagram
- Slide deck

### Step 7: Demo (5-10 min)

Three layers:
- **What** — show the artifact working
- **Why** — show the people, the stuck points, the value
- **How** — show the factory, the method, the roles

## The factory outputs

- An artifact (varies)
- A demo (5-10 min, three layers)
- A method (this README + the prompt bank + the decision tree)

## What makes the factory reusable

- The interview script works for any behavior gap
- The extraction is mechanical (60 sec per person)
- The decision tree generalizes (pick what's demo-able)
- The three-layer story arc works for any artifact

## Run it again

Different city: same script, new interviewees.
Different theme: same script, different stuck points.
Different problem: same factory, different artifact.
