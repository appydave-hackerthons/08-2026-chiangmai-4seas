## Three-layer story at the end

1. **What we built** — the artifact, demo it
2. **How it meets the needs** — the people, the stuck points, the value
3. **How we built it** — the factory, the method, the roles

## Decision criteria (after ideation)

- 2+ stuck points produced concrete, demo-able micro apps → demo the strongest
- Stuck points too generic to ideate against → demo the nudge web app (or whatever else works)
- Neither but the factory is interesting → demo the method itself
- Whatever else surfaced → let the data drive
